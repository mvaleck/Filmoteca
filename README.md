# 🎬 Filmoteca

Um projeto pessoal desenvolvido com o objetivo de **praticar React, styled-components, requisições API e manipulação de banco de dados local**. A **Filmoteca** é um site onde exibo os filmes que gosto, com **cards interativos**, **filtragem por categoria** e comunicação com o backend via API.

---

## 📚 Sobre o Projeto

O objetivo principal deste projeto é me aprofundar em:

- Criação de componentes reutilizáveis em **React**
- Estilização moderna com **styled-components**
- Integração com **API REST** usando métodos como `GET`, `POST`, `PUT`, `DELETE`
- Armazenamento e manipulação de dados em um **banco de dados local**
- Prática com ferramentas como o **Thunder Client** para testar rotas


## 🧩 Funcionalidades Implementadas

- ✅ Exibição de filmes em formato de **cards**
- ✅ Adição de novos filmes via requisição `POST` no Thunder Client
- ✅ Renderização automática dos filmes no front-end
- ✅ Filtro por **categoria de filme** (comédia, romance, etc.)
- ✅ Estruturação inicial de **banco de dados local**
- ✅ Testes com rotas da API (`GET`, `POST`, `PUT`, `DELETE`)
